`project_multi_year` prices grid-services income from each simulated age's own fleet, seed and bisection-trial ages alike (§4, §8.1), so capacity-at-events income falls with battery SOH; the 0.5.0 tag books the age-0 event figure at every age. A flat rate prices the batteries of the fleet `simulate` returns, which `simulate_fleet` pairs with the scenario's homes, so the flat figure is unchanged. An event window the simulated period never enters is named in one `UserWarning` per projection (§4); the 0.5.0 tag prices it at £0 silently.
