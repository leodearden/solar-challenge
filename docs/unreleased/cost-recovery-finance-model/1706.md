The project capex (§6) gains a fifth term: each battery's `max_discharge_kw`
priced at `FinanceConfig.battery_inverter_cost_per_kw_gbp`, the battery
inverter-charger's cost per kW, read from the `finance:` block key of the same
name. A home without a battery adds nothing. The cost defaults to 0, so no figure
of an existing scenario moves; a reader sets it to price the inverter-charger.

`optimize configs`' ranking compares each configuration with a reference
configuration (§9), by default the smallest battery at the smallest PV. Each
ranked row's extra capex per home and outlay change at the solved rate are its
figure less the reference's; its grid-services income is its own year-1 income
per home; it pays for itself when it is feasible and its outlay is not above the
reference's. The ranking is the cost-recovery ranking, unchanged.
