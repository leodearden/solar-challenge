the `sim_days_h` by which a home's window under 360 days is annualised (§4, *Annual basis*) is its calendar days, as `calculate_summary` now counts them. For a window that crosses the October clock change but not the March one, such as 2024-10-01 to 2024-11-30, that is 61 days, so `k_h = 365/61`; the 0.5.0 tag's `simulation_days` counts 62.
