On the physics path a battery's PV charge loss is no longer booked as export, so it no longer earns SEG income, and grid charging's charge loss is now imported, so import cost and the informational `total_grid_charge_cost_gbp` rise and basis-C own-use (demand − import, §2) falls by it; the 0.5.0 tag books the battery's charge on the energy it stored, after its charge losses. Measured on `scenarios/bristol-phase1-flex.yaml` (100 homes, 2024, committed Bristol TMY, at main 3dd45073 and with this change): export 260,369.288 to 259,864.839 kWh, SEG income (export at 4.1 p) £10,675.14 to £10,654.46; import 194,119.676 to 196,796.663 kWh, import cost £23,069.57 to £23,310.50; grid charge 104,402.491 to 107,079.478 kWh; basis-C own-use 163,131.393 to 160,454.406 kWh (−1.64%), so a solved own-use rate rises.
