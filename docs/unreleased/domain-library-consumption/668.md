The frozen contract now covers, for every class it pins but an Enum, whether a
positional class pattern such as `case Location(lat, lon)` matches its
instances by its constructor's positional parameters, spelled `match_args` in
its kind: `dataclass[eq, frozen, match_args] (...)` for a dataclass, and
`class[match_args] (...)` for any other class. Every pinned dataclass with a
positional field reads `match_args`; `SelfConsumptionStrategyConfig` in
`solar_challenge.dispatch`, which has no field, does not, and no other pinned
class sets `__match_args__`. No class changes: the lock now pins what instances
already did. Consumers need no change when they re-pin.
