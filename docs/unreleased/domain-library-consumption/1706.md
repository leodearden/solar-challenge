`FinanceConfig` gains a last field, `battery_inverter_cost_per_kw_gbp`, default
`0.0`: the battery inverter-charger's capex per kW of each battery's
`max_discharge_kw`, a finite number of at least 0, refused naming
`battery_inverter_cost_per_kw_gbp`. Its positional construction is unchanged. A
`finance:` block reads it as a key of the same name, and `scenario_knobs` gains
its finance knob of the same name. The 0.6.0 tag has none of these. Consumers
need no change when they re-pin.
