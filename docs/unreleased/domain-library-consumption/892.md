`solve_cost_recovery_rate` takes `simulate` as a required keyword-only argument,
typed as `fleet.FleetSimulate`, as `finance.project_multi_year` does (task 885's
note). A call that passes none raises `TypeError` naming `simulate` before any
fleet is simulated, where the 0.5.0 tag resolved a default simulator behind the
call. Consumers that call it with no `simulate` pass
`simulate=default_runner().simulate`, with `default_runner` from
`solar_challenge.fleet`, to simulate as that default did, when they re-pin. One
that relied on `set_weather_cache` reaching that default, which task 827 retires
at the same release, passes
`simulate=FleetRunner(weather=PvgisTmy(WeatherCache(d)), home_simulator=simulate_home).simulate`
instead, with `simulate_home` from `solar_challenge.home`.
