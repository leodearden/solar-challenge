`DispatchDecision` gains a last field, `export_kw`, default `0.0`: the battery
power in kW a strategy asks for beyond the home's shortfall, sent to the grid.
It is finite and at least 0, and is refused above 0 alongside a `charge_kw` or
`grid_charge_kw` above 0, as `discharge_kw` is, with the message
`Cannot charge and export simultaneously` or
`Cannot grid-charge and export simultaneously`; the 0.6.0 tag lacks it.
Consumers need no change when they re-pin.
